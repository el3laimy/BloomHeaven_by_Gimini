## 📋 تفاصيل المهام التنفيذية

### المرحلة 0 — تثبيت الأساس وخط أنابيب الأصول (مكتملة ✅)
1. **توحيد مصدر البيانات:** إنشاء ملفات `data/flowers.json`، `data/bouquets.json`، `data/perfumes.json`، `data/requests.json`، `data/upgrades.json`.
2. **معالجة أصول `BloomHeaven`:** استخراج الشفافية `RGBA` لصور الوردة الـ 6 وضبط نقطة الارتكاز السفلية (`Bottom-Center Pivot`).
3. **تفكيك الواجهة:** تحويلها إلى مكونات ومشاهد مستقلة (Tool Dock, Seed Bar, Plot Card, Top Bar, Order Rail, Inventory Drawer).
4. **أتمتة الفحص الشامل:** سكريبت مركزي `tools/validate_project.py` لاختبار كافة المشاهد والأصول والأصوات.

### المرحلة 1 — حلقة اللعب المستدامة ونظام الحفظ (مكتملة ✅)
1. **Save/Load V1:** حفظ متكامل لكافة جوانب الحديقة، النقود، المخزون، الأحواض، عينات التهجين، ومؤقتات الطلبات.
2. **نظام النمو المتفرع بالتشذيب:** دعم المراحل الـ 6 مع أداة التشذيب (Pruning) لإنتاج زهور عنقودية أو زهور فردية ملكية (Hero Bloom ★★★).
3. **القوائم والتوجيه:** `MainMenu`, `PauseMenu`, `SettingsMenu`, و جولة Onboarding FTUE تعليمية.

### المرحلة 2 — الانغماس الصوتي والمؤثرات البصرية (مكتملة ✅)
1. **AudioManager:** حوض تشغيل صوتي متعدد القنوات بـ 9 مؤثرات SFX مدمجة وموسيقى محيطية هادئة.
2. **Visual Polish:** جزيئات ولمعان التفتح، رذاذ السقي، غبار الزراعة، تساقط البتلات، شيدر نسيم الرياح، ونصوص عائمة للأرباح.

### المرحلة 3 — سلسلة التصنيع المتقدمة والوراثة (G2)
1. **وراثة الجيل الثاني (G2):** محرك وراثة مندلي متكامل مع تهجين السلالات (Rose, Lavender, Sunflower, Roselight...).
2. **مختبر التهجين وورشة الباقات:** واجهات تفاعلية كاملة (`BreedingModal`, `BouquetModal`, `JournalModal`).
3. **قيد الإنجاز:** واجهة تقطير العطور (`Perfume Distillery Modal`) ومبنى خلايا النحل (`Beehives & Honey`).

### المرحلة 4 — كشك البيع والطلبات والترقيات
1. **طلبات الزبائن والكومبو (Fiona Finch Rush):** نظام صبر الزبائن وإكراميات السرعة ومضاعف الكومبو حتى 2x.
2. **متجر الترقيات:** 5 ترقيات مدعومة باللغتين ومربوطة بأثر حقيقي في اللعبة وسرعة ليلي.
3. **شخصية ليلي:** حركة متتابعة واقعية، طابور مهام سلس، وأدوات محمولة في اليد.
4. **قيد الإنجاز:** كشك بيع المارة التلقائي ومسابقات الزهور الإقليمية (Garden Cups).

### بوابة الصقل والتثبيت (Polish & Hardening Gate — مكتملة 💎)
- [x] ربط أداة السماد صراحةً بترقية `fertilizer_box` ومنع استخدامها قبل الشراء مع إشعار وتنبيه صوتي.
- [x] حفظ واستعادة مؤقتات صبر الزبائن وسلسلة الكومبو في ملف الحفظ لمنع تصفيرها.
- [x] إضافة مؤشر وتنبيه صوتي/بصري ناعم لنافذة تشذيب الزهرة الملكية (Hero Bloom ★★★) لضمان عدم تفويتها.
- [x] دعم زر `ESC` لإغلاق النوافذ المنبثقة النشطة أولاً بسلاسة قبل فتح قائمة الإيقاف المؤقت.
- [x] إضافة تأثيرات الأرقام العائمة عند إنجاز الطلبات والإكراميات السريعة.
- [x] توسيع أداة التحقق المركزية `tools/validate_project.py` لتغطي 19 مشهداً، 35 سكريبت، كافة المؤثرات الصوتية، و 25 سبرايت للمراحل.

### المرحلة 5 — الموبايل والتعريب والتصدير (الخطوة القادمة)
1. **تحكم اللمس:** دعم السحب والتكبير بالقرص وملاءمة الشاشات المختلفة.
2. **التعريب الكامل:** دعم العربية والإنجليزية مع RTL ونظام `tr()`.
3. **تصدير أندرويد:** بناء AAB/APK وثبات 60 FPS تحت ميزانية أداء 250MB RAM.
